# Personal Engineering and Design Portfolio

Static portfolio site for Xiangyu Xiao, a mechanical engineering PhD with UX, 3D, and industrial design work.

## Pages

- `index.html`: compact homepage and section index.
- `about.html`: profile and capabilities.
- `projects.html`: Industrial Metaverse, HCI, and Product Design project groups.
- `publications-activities.html`: research outputs, talks, exhibitions, and teaching.
- `photography-more.html`: photography, visual studies, and more-than-design work.

## Edit These First

- `index.html`: adjust homepage positioning and directory copy.
- The subpage HTML files: replace placeholder project, publication, activity, and photography text with final content.
- `styles.css`: adjust colors, spacing, and visual style.
- `script.js`: controls the animated technical canvas on the homepage.

## Preview

Open `index.html` directly in a browser, or run a simple local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
